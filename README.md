## Overview

The `atc-assets` module forms a core pillar of the A-TownChain ecosystem under specification **ATC-90**. It provides full-featured ATCLang implementation for key infrastructure capabilities across `L8 — Assets`.

## Modules Summary

- **`render/render_engine.atc`**: 3D Render Engine — Mesh, material, lighting, camera
- **`shader/shader_system.atc`**: Shader System — Vertex, fragment, compute shaders
- **`animation/animation_engine.atc`**: Animation Engine — Skeletal, morph, particle, timeline
- **`audio/audio_engine.atc`**: Audio Engine — 3D spatial audio, mixing, effects, streaming
- **`media/media_generator.atc`**: Media Generator — AI-powered image, video, text generation
- **`vault/asset_vault.atc`**: Asset Vault — NFT-backed asset storage, metadata, licensing

## Getting Started

1. Ensure the ATCLang toolchain v0.3+ is installed.
2. Clone this repository into your workspace.
3. Import modules into your ATCLang entrypoints.
